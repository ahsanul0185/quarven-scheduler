# Quarven Scheduler

A simple, browser-based weekly staff scheduling app for facilities managers.

## What it does

Upload three CSV files (employees, shifts, tasks) plus an optional config file, click **Generate Schedule**, and the app produces a full weekly roster. It checks every business rule automatically and reports any problems clearly.

## Tech stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Recharts
- PapaParse

No server, no database, no login, no external services.

## Quick start

```bash
npm install
npm run dev
```

Then open the URL shown in your terminal (usually `http://localhost:5173/`).

To build for production:

```bash
npm run build
```

The built files are placed in `dist/` and can be opened directly from any static file server:

```bash
npm run preview
```

## How to use

1. Upload the required CSV files or click **Load sample files**.
2. Click **Generate Schedule**.
3. Browse the six dashboard views: Overview, Weekly Grid, Floor View, Tasks & Teams, Breaks, Conflicts.
4. Export the schedule CSV, problems CSV, or printable HTML report from the top bar.

## Input files

### `employees.csv`

| Column | Description |
|--------|-------------|
| `employee_id` | Unique ID |
| `employee_name` | Display name |
| `site` | Site the employee works at |
| `role` | `cleaning`, `security`, or `maintenance` |
| `skills` | Semicolon-separated skills |
| `monday` … `sunday` | `available`, `unavailable`, or `partial` |

`partial` means the employee can only be assigned to a shift of 6 hours or less that day.

### `shifts.csv`

| Column | Description |
|--------|-------------|
| `shift_id` | Unique ID |
| `site` | Site |
| `role` | Required role |
| `day` | `monday` … `sunday` |
| `start_time` | HH:mm |
| `end_time` | HH:mm |
| `min_staff` | Minimum staff needed |
| `max_staff` | Maximum staff allowed |

### `tasks.csv`

| Column | Description |
|--------|-------------|
| `task_id` | Unique ID |
| `shift_id` | Parent shift |
| `task_name` | Task description |
| `floor` | Floor where task happens |
| `required_role` | Role needed |
| `required_skill` | Skill needed (blank = any) |
| `required_headcount` | How many people the task needs |

### `config.json` (optional)

```json
{
  "min_rest_hours": 10,
  "max_weekly_hours": 48,
  "max_consecutive_days": 5,
  "break_threshold_hours": 6,
  "break_duration_minutes": 30,
  "partial_day_max_hours": 6
}
```

## Scheduling rules

1. Role and site must match (skill match if a skill is required).
2. Employees are never scheduled on unavailable days.
3. On partial days, only shifts ≤ 6 hours are allowed.
4. At least 10 hours rest between shifts.
5. No more than 48 hours per week.
6. No more than 5 consecutive work days.
7. Shifts over 6 hours get a 30-minute break automatically.
